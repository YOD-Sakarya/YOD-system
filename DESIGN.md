# Union workspace

Arabic-first working environment for the Yemeni Students Union in Sakarya.
Primary tasks: find a committee document, review a proposal, and take part in a vote.

## Visual direction

Union red #a52c38, deep slate #202b3b, paper white #ffffff, cool canvas #f5f7fa,
muted ink #657387, and approval green #23735c. Use Noto Sans Arabic for readable
Arabic interface text. Strong heading weights, tabular numerals, quiet body text.
Right-aligned content; the right sidebar anchors the workspace. The top bar
contains search and identity. A compact overview leads into a document table and
an upcoming-events rail. The union logo is retained.

```
| identity and search                         | union identity |
| overview and primary action                 | navigation     |
| activity counts                             | committees     |
| document table              | event agenda  |                |
```

The committee structure, three-role review progress, Arabic dates, and voting
outcomes carry the identity. Avoid unrelated stock illustrations, decorative
charts, inflated sample metrics, and uniform cards for every piece of content.
Use a document table for scanability and a compact agenda for dates. The red
accent belongs to navigation and primary actions rather than large gradients.

## Review before implementation

A generic dashboard of four charts would hide the union's actual work. Replace
it with a document ledger, a visible review queue, and active ballot summaries.
Keep real data separate from a clearly marked, read-only design preview.
Support mobile navigation, visible focus, dialog keyboard interaction, reduced
motion, empty states, and actionable errors.

Brand naming: YOD abbreviates the Turkish Yemenli Öğrencileri Derneği. Do not transliterate it as an Arabic word; use مساحة الاتحاد in the Arabic interface.
